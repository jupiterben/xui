# xui 项目蓝图

多框架 Headless UI：规范与逻辑下沉核心，各框架只做适配。

## 战略要求

1. **Headless** — 只约定状态、行为与可访问性；样式由消费者决定，不捆绑完整视觉体系。
2. **规范先于实现** — `@xui/core` 定义跨框架契约与纯逻辑；`@xui/react` / `@xui/vue` 仅做框架绑定，公开 API 对齐。
3. **单向依赖** — 框架包依赖 core，互不依赖；core 不依赖任何 UI 框架。
4. **主题可替换** — 视觉由语义主题输入展开为 Token（CSS 变量）；支持预设、自定义与生成式主题。
5. **可扩展** — 新框架适配复用同一 core；新组件先定规范，再平行落地各适配层。
6. **交互态统一** — 接受用户操作的组件统一具备 `disabled` 与 `loading`；二者任一为真则不可操作；a11y 映射为 `disabled` + `aria-busy`。
